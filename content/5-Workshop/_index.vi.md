# 5. Workshop: Nền tảng Phân tích Nhận diện Cảm xúc Khuôn mặt Serverless

2. **5.2 Yêu cầu tiên quyết:** [Môi trường cục bộ, cấu hình AWS CLI và cài đặt thư viện](5.2-Prerequiste/)

5. **5.5 Kiểm thử / Chính sách:** [Chạy thử nghiệm toàn trình (End-to-End) và xác minh log, cơ sở dữ liệu](5.5-Testing-Policy/)
